# Pathfinder

A driving-route planner. You list addresses, and the app orders them into one route on a map.

The application can be accessed at https://pathfinder-aird.onrender.com/

The shell runs in Docker. Setup and commands are in [docs/local-development.md](docs/local-development.md). What gets built next is in [docs/PLAN.md](docs/PLAN.md).
